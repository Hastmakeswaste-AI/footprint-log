# GCP Data Workflow Skill

This Copilot skill scaffolds dataset workflows for GCP Tier0->Tier1 flows.

Install locally (example):
- copy this folder to your Copilot plugins location or package as zip
- install: `copilot plugin install <path_or_id>`

Usage examples:
- `python handler.py scaffold sales_2026` (creates workflows/sales_2026/ with design.md etc.)

Run tests:
- from skill folder: `pip install pytest && pytest -q`
