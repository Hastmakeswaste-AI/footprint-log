# Python Tank Game

A simple two-player tank game built with Python and Pygame.

## Controls

- Player 1: `W` / `A` / `S` / `D` to move, `Space` to shoot
- Player 2: Arrow keys to move, `Enter` to shoot

## Requirements

- Python 3.8+
- Pygame

## Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the game:
   ```bash
   python main.py
   ```

## Notes

- Player 1 and Player 2 can shoot bullets.
- Walls block bullets.
- The first player to hit the opponent wins.
